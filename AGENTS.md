# Repository instructions

## Permanent software-only scope

This repository is a software simulation and systems-engineering project. Never create or reintroduce KiCad schematics, PCB layouts, PCB footprints, symbol libraries, fabrication packages, hardware wiring files, or netlists intended to represent verified physical connections.

Do not introduce those artifacts under alternative filenames or formats. Prefer mathematical models, software topology representations, numerical analysis, control algorithms, automated verification, reproducible experiments, and documentation.

Firmware may be included only as hardware-independent protocol or state-machine examples. It must not depend on unverified generated hardware connections or imply physical validation.

All claims must distinguish analytical verification, software simulation, and physical measurement. Physical hardware validation is outside this repository's scope.
